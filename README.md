# aad-quests

AAD İHA Yazılım Takımı'na yeni katılanlar için görev tabanlı eğitim materyali.

---

## Nasıl Başlanır?

İçerikler düz metin editörü için değil, **[Obsidian](https://obsidian.md)** için hazırlanmıştır. Obsidian olmadan da okunabilir ama bağlantılar, callout kutuları ve görev listeleri düzgün görünmez.

### 1. Obsidian'ı kur

```bash
sudo snap install obsidian --classic
```

Ya da [obsidian.md](https://obsidian.md) adresinden manuel olarak indir.

### 2. Repoyu klonla

```bash
git clone https://github.com/Anatolia-Aero-Design/aad-quests.git
```

### 3. `Quests` klasörünü Obsidian'da aç

> Reponun kökünü değil, içindeki **`Quests`** klasörünü vault olarak açman gerekiyor.

Obsidian'ı aç → **Open folder as vault** → `aad-quests/Quests` klasörünü seç.

Bundan sonra sol panelde `INDEX` dosyasını aç ve oradan ilerle.

## Tier Sistemi

| Tier | Kimler için? |
|---|---|
| **Yazılımcı** | Herkes — Linux, Git, Python temelleri |
| **AAD Yazılımcısı** | Herkes çoğunu bilmeli — ROS2, görüntü işleme, donanım, otonom sistemler |
| **Usta AAD Yazılımcısı** | Belirli bir alanda uzmanlaşmak. Birden fazla da bilinebilir. |

Sırası önemli — bir tier'ı tamamlamadan bir sonrakine geçmen önerilmez.
